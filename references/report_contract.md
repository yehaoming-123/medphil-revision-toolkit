# Report Contract

The delivery bundle contains exactly five files:

1. `revised_manuscript.docx`
2. `revision_log.md`
3. `journal_routing_report.md`
4. `journal_fit_report.md`
5. `author_confirmation_needed.md`

The manuscript remains English. Report narrative is Chinese, while the evidence labels remain the machine-checkable values `official_requirement`, `observed_tendency`, `abstract_limited`, and `editorial_inference`.

The routing report must rank MHCP, JME, Bioethics, and JMP and state fit reasons, mismatch reasons, and evidence limits for every journal. The fit report must name the confirmed target and keep official requirements, observed tendencies, abstract-limited evidence, and editorial inference in separate sections.

The confirmation report must never silently resolve a thesis-changing, normative, evidential, or formatting choice. When no choices remain, it must state that explicitly.
